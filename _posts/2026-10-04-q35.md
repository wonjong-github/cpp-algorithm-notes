> 원본 `a`는 **R행 × C열**, 결과는 `b`. 원본 칸 `(i, j)`가 어디로 가는지로 외우면 쉬움.
> 예시 원본 (2 × 3): `[1 2 3] [4 5 6]`

**공식 표**

| 변환 | 원본 `(i, j)` → 새 위치 | 결과 크기 | 예시 결과 |
|---|---|---|---|
| 시계 90도 | `b[j][R-1-i]` | C × R | `[4 1] [5 2] [6 3]` |
| 반시계 90도 (= 시계 270도) | `b[C-1-j][i]` | C × R | `[3 6] [2 5] [1 4]` |
| 180도 | `b[R-1-i][C-1-j]` | R × C | `[6 5 4] [3 2 1]` |
| 전치 (대각선 대칭) | `b[j][i]` | C × R | `[1 4] [2 5] [3 6]` |
| 좌우 반전 | `b[i][C-1-j]` | R × C | `[3 2 1] [6 5 4]` |
| 상하 반전 | `b[R-1-i][j]` | R × C | `[4 5 6] [1 2 3]` |

**시계 방향 90도 (가장 많이 씀)**

```cpp
vector<vector<int>> rotCW(const vector<vector<int>> &a) {
    int R = a.size(), C = a[0].size();
    vector<vector<int>> b(C, vector<int>(R));      // 행·열 크기가 바뀜!
    for (int i = 0; i < R; i++)
        for (int j = 0; j < C; j++)
            b[j][R - 1 - i] = a[i][j];
    return b;
}
```

- 외우는 법: **원래 행 번호 `i`가 새 열 번호가 되는데, 거꾸로 (`R-1-i`)**. 원래 열 번호 `j`는 그대로 새 행 번호.
- 맨 윗줄 `[1 2 3]`이 → 오른쪽 세로줄 (위→아래로 1, 2, 3)이 됨.
- 같은 회전을 "새 칸을 어디서 가져오나"로 쓰면: `b[i][j] = a[R-1-j][i]` (i < C, j < R).

**반시계 90도 / 180도**

```cpp
b[C - 1 - j][i] = a[i][j];         // 반시계 90도  (b 크기: C x R)
b[R - 1 - i][C - 1 - j] = a[i][j]; // 180도        (b 크기: R x C)
```

**여러 번 회전**

```cpp
k = ((k % 4) + 4) % 4;              // 음수(반시계)도 처리. 4번 돌리면 원래대로
while (k--) a = rotCW(a);
// 시계 3번 = 반시계 1번, 시계 2번 = 180도
```

**정사각형을 제자리에서 시계 90도: 전치 → 각 행 뒤집기**

```cpp
void rotCWInPlace(vector<vector<int>> &a) {        // N x N 전용
    int N = a.size();
    for (int i = 0; i < N; i++)
        for (int j = i + 1; j < N; j++)
            swap(a[i][j], a[j][i]);                 // 전치
    for (auto &row : a) reverse(row.begin(), row.end());   // 좌우 반전
}
// [1 2 3] [4 5 6] [7 8 9] → [7 4 1] [8 5 2] [9 6 3]
```

- 반시계 90도 = 전치 → **위아래** 뒤집기 (`reverse(a.begin(), a.end())`).

**함정**

| 함정 | 대처 |
|---|---|
| 원본을 덮어쓰면서 읽음 → 값이 섞임 | **새 배열 `b`에 쓰거나** 복사본에서 읽기 (위 rotCWInPlace처럼 swap으로 하는 경우 제외) |
| 직사각형인데 결과 크기를 R × C로 만듦 | 90도 / 270도 회전은 **C × R** |
| 공식에서 `R`과 `C`를 헷갈림 | 2 × 3 같은 **직사각형 예시**로 확인 (정사각형은 R = C라 실수가 안 드러남) |
| 테두리만 돌리는 문제와 혼동 | 테두리 회전은 "값을 한 칸씩 당기기" 방식 (행렬 테두리 회전하기 테스트 참고) |

- 쓰이는 문제: 자물쇠와 열쇠 (Q34), 스티커 붙이기, 테트로미노 회전, 2048 게임(방향마다 회전 후 같은 처리).
