**문제 핵심**: 열쇠(M×M)를 회전·이동해서 자물쇠(N×N)의 모든 홈(0)을 돌기(1)로 채우되, 자물쇠 돌기와 열쇠 돌기가 부딪히면 안 됨. 열쇠는 **자물쇠 밖으로 나가도 됨**.

**아이디어 4단계**

1. **넓힌 판 만들기**: 크기 `N + 2(M-1)`인 판 가운데(`M-1, M-1`)에 자물쇠를 놓음 → 열쇠가 밖으로 나가는 경우도 **범위 검사 없이** 처리.
2. **놓아 보기**: 판 위에 열쇠 값을 **더함** (자물쇠 1 + 열쇠 1 = 2, 자물쇠 0 + 열쇠 1 = 1).
3. **검사**: 자물쇠 영역이 **모두 정확히 1**이면 성공. `0` = 빈 홈, `2` = 돌기 충돌.
4. **원상복구**: 실패하면 더했던 열쇠 값을 **빼서** 되돌리고 다음 위치로 (백트래킹과 같은 구조). 모든 위치를 본 뒤 열쇠를 90도 돌려서 반복 (총 4번).

```
M = 3, N = 3 → 판 크기 3 + 2·2 = 7

. . . . . . .      열쇠 왼쪽 위가 (0,0) ~ (4,4)까지 이동
. . . . . . .      (0,0)이면 열쇠의 오른쪽 아래 한 칸만 자물쇠에 걸침
. . L L L . .
. . L L L . .      L = 자물쇠 (start = M-1 = 2)
. . L L L . .
. . . . . . .
. . . . . . .
```

```cpp
// 시계 방향 90도 회전: (i, j) → (j, N-1-i)
void rotate90(vector<vector<int>> &m) {
    int N = m.size();
    vector<vector<int>> copy = m;                  // 원본을 복사해 두고 새 위치에 씀
    for (int i = 0; i < N; i++)
        for (int j = 0; j < N; j++)
            m[j][N - 1 - i] = copy[i][j];
}

// 큰 판 위 (r, c)에 열쇠를 sign(+1: 놓기, -1: 빼기)만큼 더함
void place(vector<vector<int>> &board, const vector<vector<int>> &key, int r, int c, int sign) {
    int M = key.size();
    for (int i = 0; i < M; i++)
        for (int j = 0; j < M; j++)
            board[r + i][c + j] += sign * key[i][j];
}

// 자물쇠 영역의 모든 칸이 정확히 1인가? (0 = 빈 홈, 2 = 돌기 충돌)
bool unlocked(const vector<vector<int>> &board, int start, int N) {
    for (int i = 0; i < N; i++)
        for (int j = 0; j < N; j++)
            if (board[start + i][start + j] != 1) return false;
    return true;
}

bool solution(vector<vector<int>> key, vector<vector<int>> lock) {
    int N = lock.size(), M = key.size();
    int start = M - 1;                             // 자물쇠가 놓이는 위치
    int L = N + 2 * (M - 1);                       // 열쇠가 밖으로 나가도 되도록 넓힌 판

    vector<vector<int>> board(L, vector<int>(L, 0));
    for (int i = 0; i < N; i++)
        for (int j = 0; j < N; j++)
            board[start + i][start + j] = lock[i][j];

    for (int rot = 0; rot < 4; rot++) {
        for (int r = 0; r + M <= L; r++) {         // 열쇠 왼쪽 위 = (r, c)
            for (int c = 0; c + M <= L; c++) {
                place(board, key, r, c, +1);       // 놓아 보고
                if (unlocked(board, start, N)) return true;
                place(board, key, r, c, -1);       // 원상복구
            }
        }
        rotate90(key);
    }
    return false;
}
```

**복잡도**: 회전 4 × 위치 (N+M-1)² × (놓기 M² + 검사 N²) → 최대 20일 때 약 4 × 39² × 800 ≈ 500만 → 충분히 빠름.

**함정**

| 함정 | 결과 |
|---|---|
| 열쇠를 자물쇠 **안에서만** 움직임 | 열쇠 가운데 돌기로 자물쇠 구석 홈을 채우는 경우를 놓침 |
| 홈만 채우면 성공으로 봄 | 돌기끼리 부딪히는 경우(값 2)를 통과시킴 |
| 회전을 안 함 / 회전 공식 오류 | 회전해야만 맞는 경우를 놓침 |
| 판을 매번 새로 복사 | 동작은 하지만 느림 → 더하고 빼는 방식이 효율적 |
| 회전 시 원본을 덮어쓰며 읽음 | 값이 섞임 → 복사본에서 읽고 원본에 씀 |

- 테스트 팁: "밖으로 밀어야 맞는" 테스트는 **열쇠 가운데에 돌기**를 둘 것. 구석 돌기는 회전하면 반대쪽 구석으로 가서, 안에서만 움직이는 잘못된 풀이도 통과해 버림.
- 같은 틀이 쓰이는 문제: 퍼즐 조각 맞추기, 스티커 붙이기(백준 18808) 등 **"모양을 회전·이동해서 판에 맞추기"**.
