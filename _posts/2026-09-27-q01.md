{% raw %}
```cpp
// 벡터 전체를 서로 교환: O(1) (내부 포인터만 교환, 원소 복사 X)
a.swap(b);
std::swap(a, b);

// 벡터 안 원소끼리 교환
std::swap(v[i], v[j]);
std::iter_swap(v.begin() + i, v.begin() + j);

// 메모리까지 비우기 (swap trick)
vector<int>().swap(v);
```

- 벡터 전체를 스왑해도 반복자는 무효화되지 않고, **상대편 벡터**를 가리키게 됨.
