> 직사각형 영역의 **테두리만** 한 칸씩 도는 문제. 좌표: 왼쪽 위 `(x1, y1)`, 오른쪽 아래 `(x2, y2)` (0부터 시작).
> 문제 좌표가 1부터면 처음에 한 번만 `-1` 해 두기.
> 행렬 전체를 90도 돌리는 공식(Q35)과는 다른 문제.

**핵심 원리: 한 칸 저장 → 반대 방향으로 당겨 오기 → 저장한 값을 마지막 빈칸에**

- 값을 **진행 방향으로 밀면** 다음 칸 값을 덮어써서 잃어버림.
- **진행 방향의 반대쪽에서 당겨 오면** 덮어쓰는 칸이 항상 "이미 옮긴 칸"이라 안전. 처음 한 칸(`tmp`)만 저장.

예시 (3 × 4 전체 테두리)

```
원본            시계 1칸          반시계 1칸
 1  2  3  4      5  1  2  3       2  3  4  8
 5  6  7  8      9  6  7  4       1  6  7 12
 9 10 11 12     10 11 12  8       5  9 10 11
```

**1) 시계 방향 1칸**

```cpp
void borderCW(vector<vector<int>> &m, int x1, int y1, int x2, int y2) {
    int tmp = m[x1][y1];                                          // 왼쪽 위 저장
    for (int r = x1; r < x2; r++) m[r][y1] = m[r + 1][y1];        // 왼쪽 열: 아래 → 위로 당김
    for (int c = y1; c < y2; c++) m[x2][c] = m[x2][c + 1];        // 아래 행: 오른쪽 → 왼쪽으로 당김
    for (int r = x2; r > x1; r--) m[r][y2] = m[r - 1][y2];        // 오른쪽 열: 위 → 아래로 당김
    for (int c = y2; c > y1 + 1; c--) m[x1][c] = m[x1][c - 1];    // 위 행: 왼쪽 → 오른쪽으로 당김
    m[x1][y1 + 1] = tmp;                                          // 저장값은 왼쪽 위의 "오른쪽" 칸
}
```

- 순서: **저장한 칸이 있는 변부터** 당김 (왼쪽 위를 저장 → 그 칸을 채우는 왼쪽 열부터).
- 이동한 값 중 최솟값이 필요하면 각 반복문에서 옮긴 값마다 `min` 갱신 (행렬 테두리 회전하기).

**2) 반시계 방향 1칸**

```cpp
void borderCCW(vector<vector<int>> &m, int x1, int y1, int x2, int y2) {
    int tmp = m[x1][y1];                                          // 왼쪽 위 저장
    for (int c = y1; c < y2; c++) m[x1][c] = m[x1][c + 1];        // 위 행: 오른쪽 → 왼쪽으로 당김
    for (int r = x1; r < x2; r++) m[r][y2] = m[r + 1][y2];        // 오른쪽 열: 아래 → 위로 당김
    for (int c = y2; c > y1; c--) m[x2][c] = m[x2][c - 1];        // 아래 행: 왼쪽 → 오른쪽으로 당김
    for (int r = x2; r > x1 + 1; r--) m[r][y1] = m[r - 1][y1];    // 왼쪽 열: 위 → 아래로 당김
    m[x1 + 1][y1] = tmp;                                          // 저장값은 왼쪽 위의 "아래" 칸
}
```

**3) 테두리를 1차원으로 꺼내서 k칸 돌리기 (방향·칸 수 자유, 가장 덜 헷갈림)**

```cpp
// 테두리 칸 좌표를 시계 방향 순서로 모음
vector<pair<int, int>> borderCells(int x1, int y1, int x2, int y2) {
    vector<pair<int, int>> cells;
    for (int c = y1; c < y2; c++) cells.push_back({x1, c});      // 위 행 →
    for (int r = x1; r < x2; r++) cells.push_back({r, y2});      // 오른쪽 열 ↓
    for (int c = y2; c > y1; c--) cells.push_back({x2, c});      // 아래 행 ←
    for (int r = x2; r > x1; r--) cells.push_back({r, y1});      // 왼쪽 열 ↑
    return cells;
}

void borderRotate(vector<vector<int>> &m, int x1, int y1, int x2, int y2, int k) {   // k>0 시계, k<0 반시계
    auto cells = borderCells(x1, y1, x2, y2);
    int n = cells.size();
    vector<int> vals(n);
    for (int i = 0; i < n; i++) vals[i] = m[cells[i].first][cells[i].second];
    k = ((k % n) + n) % n;                                        // k가 둘레보다 커도, 음수여도 OK
    rotate(vals.begin(), vals.end() - k, vals.end());             // 오른쪽으로 k칸 = 시계 k칸 (<algorithm>)
    for (int i = 0; i < n; i++) m[cells[i].first][cells[i].second] = vals[i];
}
```

- `std::rotate(first, middle, last)`: `middle`이 맨 앞으로 오도록 돌림. `end() - k`를 주면 **오른쪽으로 k칸**.
- 한 칸씩 k번 돌리는 것보다 빠름 (k가 크면 `k % 둘레`로 줄어듦).
- 1·2번 방식과 결과가 같음: 크기·영역·칸 수·방향을 무작위로 바꿔 3000번 비교해 모두 일치.

**4) 여러 겹 동시에 돌리기 (백준 16926 배열 돌리기 등)**

```cpp
int R = m.size(), C = m[0].size();
for (int layer = 0; layer < min(R, C) / 2; layer++)               // 바깥 테두리부터 안쪽으로
    borderRotate(m, layer, layer, R - 1 - layer, C - 1 - layer, k);
```

```
4 x 4 모든 겹 반시계 1칸
 1  2  3  4        2  3  4  8
 5  6  7  8   →    1  7 11 12
 9 10 11 12        5  6 10 16
13 14 15 16        9 13 14 15
```

| 함정 | 대처 |
|---|---|
| 진행 방향으로 밀어서 값을 덮어씀 | **반대쪽에서 당겨 오기** + 처음 한 칸만 `tmp` |
| 모서리 칸을 두 번 옮기거나 빠뜨림 | 각 반복문 범위가 모서리에서 겹치지 않는지 (`< x2`, `> y1 + 1` 등) 확인 |
| `tmp`를 넣을 칸을 잘못 고름 | 시계: `(x1, y1+1)`, 반시계: `(x1+1, y1)` |
| 1부터 시작하는 좌표를 그대로 사용 | 처음에 `-1` |
| 헷갈리면 | 3번(1차원으로 꺼내서 돌리기)이 가장 안전 |
