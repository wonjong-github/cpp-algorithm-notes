{% raw %}
```cpp
void swap(int a, int b)   { int c = a; a = b; b = c; }   // ❌ 복사본만 바뀜
void swap(int &a, int &b) { int c = a; a = b; b = c; }   // ✅ 참조로 원본 수정
```

- 게다가 `using namespace std;` 상태에서 `swap`이라는 이름을 직접 만들면 `std::swap`과 헷갈리거나 모호해질 수 있음 → 그냥 `std::swap` 사용.
